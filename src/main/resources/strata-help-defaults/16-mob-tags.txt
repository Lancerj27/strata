# Mob tags
@screen OverridesScreen:mob_tags
Where: World > Mobs > Data... > Mob tags.

Groups of mobs the game uses for its rules, grouped by theme: Aquatic, Undead, Raiders, Arthropods, Immunities, Riding and boats, Attacks and targets, Spawning, Other.
A tag holds the game's members and every mod's together.

What you can do here
- Select a tag to see its members.
- Duplicate element adds a member: type its id in Value first, then Set value.
- Remove element takes one out.
- On / Off empties the tag. Restore puts the game's members back.
- Search finds a tag by name or by a member.

Tags worth knowing
- undead: Smite hurts them, healing hurts them, harming heals them.
- arthropod: Bane of Arthropods hurts them.
- raiders: join raids.
- skeletons and zombies: the game's family checks.
- freeze_immune_entity_types: powder snow does not freeze them.
- fall_damage_immune: no fall damage.
- sensitive_to_smite, sensitive_to_bane_of_arthropods, sensitive_to_impaling: the enchantment targets.
- axolotl_hunt_targets, axolotl_always_hostiles: what axolotls attack.
- can_breathe_under_water, can_turn_in_boats, dismounts_underwater: body rules.

Step by step: your variant counts as undead
1. Search "undead". Select the undead tag.
2. Duplicate element. Type strata:frost_zombie in Value. Set value.
3. Save. Smite now hurts the frost zombie.

Examples
- Stop axolotls hunting a fish: remove it from axolotl_hunt_targets.
- Make a mob immune to powder snow freezing: add it to freeze_immune_entity_types.
- No fall damage for your boss: add it to fall_damage_immune.

When it applies: from the next world load or /reload.
