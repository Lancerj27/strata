# Formulas
@screen FormulasScreen
Where: Scaling > Formulas.

The four formulas scaling uses. Each one is text.

What you can do here
- Area level: names level, local_difficulty, chunk_scale. Runs only while Chunk scaling is on.
- Mob attribute bonus and Player attribute bonus: names base, level, start_level, per_level, exponent, coefficient. The result is a fraction of base: 0.5 adds half.
- Mob XP multiplier: names level, per_level, exponent. 1 is the game's XP.
- Operators: + - * / ^ and parentheses. Functions: min, max, clamp, floor, ceil, round, abs, sqrt, log, exp, if(test, a, b).
- A formula with a problem shows it in red and Save stays off. Defaults puts Strata's own back.

Examples
- A flat bonus of 2 per level: 2 * level / base.
- A cap on the bonus: min(per_level * level, 3).
- Double XP above level 20: if(level - 20, 2, 1).

When it applies: at once, after Save. Each profile keeps its own.
