# Tags and data maps
@screen OverridesScreen
Where: the Data... menu of Items, Blocks, Mobs and Biomes.

Tags are lists the game uses for its rules: what a tool mines, what burns, what a mob eats or is tamed with.
Data maps hold values per item or block: fuel time, compost chance, waxed and oxidized forms.
A tag holds the game's members and every mod's together.

What you can do here
- Select an entry to see its fields. Data map values read as "Copper Block: Next Oxidation Stage", sorted by name.
- Select a field, type a value, Set value. Restore puts it back.
- Duplicate element adds a member: type its id in Value first.
- Remove element takes one out.
- On / Off empties a tag.

Examples
- Stone pickaxes mine diamond ore: add it to needs_stone_tool.
- Sticks burn for 10 seconds: item data, furnace fuels.
- Copper oxidizes to your own block: block data, oxidizables.

When it applies: at the next world load or /reload.
