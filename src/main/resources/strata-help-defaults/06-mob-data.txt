# Mob data
@screen MobDataScreen
Where: the mob editor, Mob data.

Every value Strata reads from the game for the mob, in tabs.
At the top of Attributes:
- Category: which mob cap it counts toward. Misc: the game never spawns it by itself.
- Mob griefing: Off, On or Default, for this mob alone.
- Passive and Converts.
- Spawn as: Normal (from spawn lists) or Special (from its special spawner).
The tabs:
- Attributes: health, armor, damage, speed, follow range and every mod's attribute.
- Type: size, fire immunity, blocks it ignores, tracking range.
- Fields: the values of its class.
- Tags: true or false for each mob tag.
- Visuals: model, texture, glowing texture, tint, scale, shadow and particles.
- Sounds: each sound with its volume and pitch.
- Body: gravity, immunities, burning in daylight, item pickup, despawning, climbing, swimming, flying, Boss, scoreboard tags, and how much it avoids each kind of terrain.
- Combat: reach, attack cooldown, sweep hits, ranged range and interval, and the projectile it fires.
- Loot & XP: its loot table, XP range, gear that always drops, and each slot's drop chance.
- Boss (when Boss is on): the bar's colour, style, name and range, dark sky, fog and boss music.

What you can do here
- Select a value, type yours, Set value. Restore puts back the value beneath.
- Blank is the game's own value.
- Grey values are locked. The line under the list says why.

Examples
- A zombie with 40 health and 0.3 speed.
- A spider twice as big: Type, size.
- A mob that never burns in daylight: Body.
- Creepers that break nothing: Mob griefing Off.
- A skeleton that fires your own projectile: Combat.

When it applies: each time the mob joins the world, and on loaded mobs when you save.
Type values and tags are for the whole mob type. Tags apply from the next world load.
