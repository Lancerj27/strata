# Cat and wolf variants
@screen OverridesScreen:mob_variants
Where: World > Mobs > Data... > Cat and wolf variants.

The wolf variants and the cat variant tags in one list, a group each.

What you can do here
- Wolf variants: each variant's wild, tame and angry textures, and the biomes it spawns in.
- Cat variant tags: which cat looks the game picks, for example full_moon_spawns.
- Select an entry, select a field, type a value, Set value.
- Duplicate element and Remove element add or take out list members.

Examples
- Snowy wolves in a modded tundra biome: add the biome to the snowy wolf's biomes.
- Only black cats on a full moon: leave only all_black in full_moon_spawns.

When it applies: from the next world load or /reload.
