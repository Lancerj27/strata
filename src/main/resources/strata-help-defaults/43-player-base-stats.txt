# Player base stats
@screen PlayerBaseStatsScreen
Where: Options > Player base stats, or Scaling > Player scaling.

The player's own values, each with what it does and the game's number.
Player scaling grows these values with the XP level. See Player scaling.

The values
- Max health: 20 is ten hearts.
- Movement speed: 0.1 is the game's walk.
- Attack damage: 1 is a bare hand.
- Attack speed: 4 is the game's.
- Armor and Armor toughness: a base before worn armor.
- Knockback resistance: 0 to 1.
- Block interaction range and Entity interaction range: reach.
- Luck: better loot and fishing.
- Safe fall distance, Fall damage multiplier, Gravity, Jump strength, Step height, Scale, and every mod's attribute.
- Select a value, type yours, Set value. Restore puts it back.

Step by step: a tougher player
1. Max health 40. Set value.
2. Block interaction range 6. Set value.
3. Every player has twenty hearts and a longer reach, at once.

Examples
- Faster walking: Movement speed 0.13.
- A tiny player: Scale 0.5.
- No fall damage: Fall damage multiplier 0.

When it applies: to every player, at once.
