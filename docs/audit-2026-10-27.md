# Strata audit

Audited 2026-10-27. Closed 2026-10-28 for release 0.3.1.

## What this repo does

Strata is a NeoForge 1.21.1 mod with an in-game editor. It stores every setting as CSV tables under `config/strata`, saves them into named profiles, and can push a profile and custom textures or sounds from an operator's game to a server.

Read for this audit: the network layer, the asset upload and download code, the table writer, rollback, undo, profile manager, commands, the commit path, and the headless test entry points.

## Findings, all fixed

1. A batch edit was not all-or-nothing and auto-saved once per mob. `Commit.once` now defers the rollback close, auto-save and reload until the whole batch ends.
2. A server could make a client register an unlimited number of mob types. The join-time list codec and `ServerEntityCache` are capped at `ServerEntityCache.MAX` entries.
3. Another thread's close wiped the rollback window. `Rollback.close` leaves a window owned by another thread open.
4. The server's asset session state machine had no test. `AssetSessionSelfTest` drives offer, ack sequence, a second offer mid-file and a late ack.
5. The mob size hook swallowed every error silently. `MobModels` now warns once per entity type.
6. `Paths.TABLES` duplicated `Paths.ROOT`. The alias is removed.

## Not checked

- The editor screens and most domain operations beyond the commit, batch and loot paths.
- The runtime mixins, spawn and scaling math, and the datapack generator.
- The fixes were confirmed by reading the code, not by running the game.
